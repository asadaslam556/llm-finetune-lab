# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work, and do not harass anyone. This applies in issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

If someone's behaviour worries you, contact the maintainer privately through GitHub ([@asadaslam556](https://github.com/asadaslam556)) rather than in a public thread. Reports are handled confidentially. The maintainer may remove comments, lock threads or block people who break these rules.
